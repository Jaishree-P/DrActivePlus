# **App Name**: ActivePlus Rehab

## Core Features:

- Appointment Booking: Allows users to book appointments through a WhatsApp integration.
- Doctor Profile: Displays the doctor's profile, qualifications, and specializations on the homepage and about page.
- Treatment Catalog: Presents the clinic's main treatments in a grid with detailed sub-treatments on dedicated pages.
- Blog Management: Enables the creation, storage, and display of blog posts, created in a dialog. Storage using local storage.
- Patient Management Dashboard: Password-protected dashboard with sidebar navigation for managing patients and doctor profile. Password is a hardcoded 6-digit passcode.
- Patient Data Management: Tools to add, view, manage, and delete patient records within the dashboard. Includes the capability to download patient bills as PDFs generated using jspdf and jspdf-autotable.
- Profile Editing: A doctor profile page within the dashboard allowing the doctor to modify profile information (name, title, bio, qualifications, etc.).  Profile saved in local storage.

## Style Guidelines:

- Primary color: Strong red (#B91C1C) to convey trust, with some dynamism and excitement, like health itself. It is saturated, to signal boldness.
- Background color: Very light red (#F8E7E7), to keep the emphasis on other, brighter parts of the app.
- Accent color: Red-orange (#D97706), chosen as the hue neighboring red, but clearly distinguished in brightness and saturation.
- Headline font: 'Belleza' sans-serif. Body font: 'Alegreya' serif.
- Modern and clear icons, relating to treatments and services offered. Consider medical iconography.
- Clean and modern layout with clear sectioning and intuitive navigation.
- Subtle transitions and animations for a smooth user experience.
